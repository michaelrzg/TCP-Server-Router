Usage Guide:

Main: <br>
java Main.java < path to csv or txt file > < # of threads desired (Optional)> <br>
if # of threads is not defined, defaults to 8.

DataGen: <br>
java dataGen.java <# of desired datapoints> < output file name (Optional) > <br>
if no output file name is defined, defualts to 'generated_data.txt'
